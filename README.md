## Cómo publicarlo en GitHub Pages

1. Sube estos archivos a tu repositorio.
2. Conserva la estructura de carpetas tal como está.
3. En GitHub, ve a Settings > Pages.
4. Selecciona la rama `main` y la carpeta raíz.
5. Espera a que GitHub genere la URL.

## Nota técnica

El portafolio usa imágenes externas alojadas en GitHub Raw y enlaces a proyectos externos. Si alguna imagen deja de cargar, revisa que el archivo siga existiendo en el repositorio fuente.
